NEED TO KNOW

Frequently asked questions

Hal penting sebelum website dipublikasikan.

Apakah website ini langsung membuat server Debian?

Tidak. Halaman ini adalah panduan interaktif di browser. Perintah terminal perlu dijalankan sendiri pada mesin Debian atau VPS yang kamu miliki.

Apakah saya perlu domain?

Tidak untuk pengujian. Website bisa diakses melalui alamat IP server. Domain diperlukan agar pengunjung memakai nama seperti contoh.com, dan dibutuhkan untuk alur HTTPS Certbot yang umum.

Apakah perintah ini aman untuk semua server?

Sesuaikan dengan versi Debian dan penyedia VPS. Sebelum mengubah firewall, pastikan akses SSH sudah diizinkan agar kamu tidak terkunci dari server. Simpan cadangan konfigurasi penting.

Kenapa website belum bisa diakses dari internet?

Periksa IP publik, aturan firewall penyedia VPS, port 80/443, status Nginx, DNS domain, serta apakah jaringan mengizinkan koneksi masuk.
